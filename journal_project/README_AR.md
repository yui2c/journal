# دفتر يوميات خاص — دليل الإعداد

هذا مشروع بداية لموقع جورنال عربي. الواجهة والغلاف والصفحات جاهزة كبداية، لكن الحفظ السحابي يحتاج ربطه بحساب Supabase ونشر الموقع.

## 1) إنشاء قاعدة البيانات والحساب
1. افتحي https://supabase.com وأنشئي مشروعًا جديدًا.
2. احتفظي برابط المشروع ومفتاح `anon` من Project Settings > API.
3. افتحي SQL Editor في Supabase.
4. انسخي محتوى `schema.sql` كاملًا وشغّليه.
5. من Authentication > Providers تأكدي أن Email مفعّل.
6. من Authentication > URL Configuration أضيفي رابط موقعك بعد نشره إلى Site URL وRedirect URLs.

## 2) ربط الموقع بـ Supabase
1. افتحي `app.js` بمحرر نصوص.
2. استبدلي `PASTE_YOUR_SUPABASE_PROJECT_URL` برابط مشروعك.
3. استبدلي `PASTE_YOUR_SUPABASE_ANON_KEY` بمفتاح anon/public.
4. لا تضعي أبدًا `service_role` key في الموقع أو تشاركيه مع أحد.

## 3) تجربة الموقع
لأن المشروع يستخدم JavaScript modules، شغّليه من استضافة أو خادم محلي، وليس بفتح index.html مباشرة.
أسهل طريقة للمبتدئة: ارفعي الملفات الثلاثة (`index.html`, `styles.css`, `app.js`) إلى GitHub ثم اربطي المستودع بـ Netlify أو Vercel لنشره. لا تنشري ملف schema.sql على أنه صفحة موقع.

## 4) فتحه من الجوال
بعد النشر افتحي رابط الموقع في Safari، ثم مشاركة > إضافة إلى الشاشة الرئيسية.

## 5) الأقسام الافتراضية
يُنشئ الموقع أول مرة الأقسام التالية:
البَوْح، مُدارسة الأفكار، مواضع الدهشة، خزائن المعرفة، مقاصد وخُطى، أثر الأيام، رفوف الأدب، شذرات، رسائل مؤجلة، بين دفّتي كتاب، أسئلة معلّقة، آفاق جديدة، هوامش، أوراق مبعثرة.

## ملاحظات مهمة
- لا تشاركي بيانات الدخول.
- احتفظي بنسخة احتياطية دورية من بياناتك وصورك.
- هذا إصدار أولي: حركة تقليب الصفحات فيه انتقال بصري بسيط، وليست محاكاة فيزيائية كاملة. كذلك الصور تُحفظ في مساحة تخزين خاصة وتُعرض بروابط مؤقتة بعد تسجيل الدخول. تظهر في مساحة معاينة أسفل الكتابة، وليست قابلة للسحب داخل الورقة في هذا الإصدار.
- الخطوط اليدوية تُحمّل من Google Fonts، لذلك تحتاج اتصال إنترنت لظهورها.
